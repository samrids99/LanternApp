# ADR 002: Working name "Lantern"

- **Status:** Accepted (working title, not final public name)
- **Date:** 2026-11-03

## Context

The app needs a name for the repository, solution and documentation. The name should suit a warm, story-first vanlife product. Options considered included Quiet Corners, Hearth & Hitch and Postmarked.

"Lantern" fits the concept in two ways: warmth (the cosy inside of the van) and light (shedding a little light on unfamiliar places). A lantern also lights a small circle rather than a whole landscape, which mirrors the region-only privacy principle (ADR 001).

## Checks carried out

- **Companies House:** the name is treated as the same as LANTERN (UK) LIMITED (company no. 08122178). This only matters if a company is registered under the name.
- **App stores:** the only notable existing app found was Lantern VPN, which is a different kind of product.
- **UK IPO trademark search:** not yet done (classes 9, 38 and 45 to check).
- **Domains and social handles:** not yet checked.

## Decision

Use **Lantern** as the working name for the repository, code namespaces (e.g. `Lantern.Api`) and documentation. This is a portfolio project, so no company registration is needed.

## Consequences

- Renaming is cheap at this stage but gets harder as code accumulates.
- Before any public release or commercial use, complete the UK IPO search and consider a distinctive variant (e.g. Little Lantern, Lantern Lay) and a descriptive app store subtitle (e.g. "Lantern: Vanlife Stays & Stories").
- Search visibility will be affected by existing "Lantern" products.
- This ADR should be revisited, and superseded if the name changes.
