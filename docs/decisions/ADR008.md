# ADR 008: Seed Data storage, upload, and testing

- **Status:** Accepted
- **Date:** 2026-11-10

## Context

Deciding on where and how to store, upload, and test seed data related to the first entity in Lantern: Regions.

## Decision

- Seed data is to live in Infrastructure/Persistence/Seed folder.
- The file is an embedded resource.
- Validation exists in a separate integration test project

## Consequences

- The domain environment stays free of specific data, holding the concept and its rules rather than entities.
- It data, the loader and the README sit together so later changes can be easily viewed alongside related files.
- An embedded resource means that it cannot be missing at runtime or go missing when deployed.
- .csproj needs the EmbeddedResource line.
- Integration tests project keeps unit tests pure with no files and database references.
- CI can run unit and integration tests separately so if integration tests get slow, I can run unit tests alone.
